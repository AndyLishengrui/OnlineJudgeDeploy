# PixelTyper · 像素代码打字训练营

> 线上地址：https://www.xmuoj.com/PixelTyper/
> 面向大一新生的代码打字训练游戏 · 复古像素 RPG · 静态前端 + 轻量排行榜后端

## 给学生的一句话

打开网址 → 按任意键 → 从「新手村」第一关开始，把屏幕上的代码一个字符不差地敲出来。
敲得越准越快，星星越多；击败每关 Boss 解锁下一大关。每天记得打一次「每日挑战」。

## 玩法规则

| 模式 | 说明 |
|---|---|
| 五大关 | 顺序平原 → 分支峡谷 → 循环回廊 → 函数圣殿 → 编译终局，每关 4~12 个小关卡（Python/C 混合） |
| Boss 战 | 每大关最后一关：限时 + 血条。敲对 = 攻击 Boss，敲错 = 扣自己血 |
| 特训营地 | 符号专项（括号/运算符/引号转义）、数字专项、高频短句 |
| 每日挑战 | 按日期出题，双倍 XP，连续打卡有成就 |
| 修炼小屋 | 个人档案：等级称号、WPM 曲线、按键热力图（红色 = 你的弱键）、成就墙 |
| 🏆 排行榜 | 登录 xmuoj 后成绩自动上传：总榜（星数/战功XP）+ 每关单榜（WPM） |
| 📦 自定义关卡包 | 老师发布的专项练习，地图上蓝色节点，成绩同样上榜 |

## 操作要点

- **敲错必须退格改正**（红色字符），准确率比速度更重要
- **Tab 键**自动补当前行的缩进空格
- 系统检测到**中文输入法**会弹警告——全程用英文输入
- 星级 = 速度 + 准确率双达标；准确率低于 80% 不得星
- 想上排行榜：先登录 xmuoj 主站（或点地图右上角徽章跳转登录），再打关

## 老师用：发布自定义关卡

1. 用管理员账号登录 xmuoj 主站（与 OJ 后台管理员同一账号，无需额外配置）
2. 打开 PixelTyper → 地图右上角出现「🛠 管理」
3. 「新建关卡包」→ 填名称/说明 → 在 JSON 框里编辑关卡数组 → 「✔ 校验」→「💾 保存发布」
4. 学生端刷新地图即可看到蓝色 📦 节点

关卡 JSON 格式（每关一个对象）：

```json
[{"title": "输出练习", "tier": 1, "lang": "py", "hint": "注意引号", "code": "print('hi')"}]
```

- `tier`：0=专项训练 / 1~5=难度（决定评星门槛，新手用 1）
- `lang`：`py` / `c` / `drill`（仅影响卡片标签配色）
- `code`：**必须纯 ASCII**（不能有中文标点），≤60 行，每行 ≤80 字符
- 每包最多 30 关；删除包不会影响已有的学生成绩记录

## 本地运行 / 二次开发

```bash
cd PixelTyper
python3 -m http.server 8899     # 打开 http://localhost:8899（无后端时自动降级本地模式）
```

题库在 `data/snippets.js`（`{id, title, tier 0~5, code, hint}`，code 必须纯 ASCII），
文案在 `data/flavor.js`。改完直接刷新页面即可。

部署：`./deploy.sh`（打包 → 上传 → docker cp 进 oj-backend → curl 验证）
排行榜/关卡包后端：见 `server/README.md`
