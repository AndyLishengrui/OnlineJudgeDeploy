# PixelTyper · 像素代码打字训练营 — 设计文档

> 面向大一新生的代码打字训练游戏 · 复古像素 RPG 风格
> 部署目标：`https://www.xmuoj.com/PixelTyper/`（oj-backend 容器 `/app/dist/PixelTyper/`，纯静态）

---

## 1. 产品定位

大一新生写代码慢，一半慢在**打字**：找键、看手、中英文输入法混用、符号键（`{}[]();:_`）不熟。
PixelTyper 把「照敲真实代码」包装成复古 RPG 冒险：**打字就是施法，敲对就是攻击**。

设计三原则：
1. **练的都是真代码** —— 题库全部来自大一课程（顺序/分支/循环/函数/PTA 风格综合），打代码 = 顺便预习语法。
2. **反馈密到每一键** —— 每个字符的键入都有声音、动画、伤害数字；错了立刻红闪 + 蜂鸣。
3. **弱点看得见** —— 每个键的错误率、耗时都被记录，生成像素键盘热力图，学生知道自己该练什么。

## 2. 视觉系统（统一像素风）

| 项 | 方案 |
|---|---|
| 色板 | **PICO-8 16 色**（复古游戏经典色板），CSS 变量统一管理 |
| 字体 | UI/标题：Fusion Pixel（缝合像素，OFL 开源，覆盖简中）+ Press Start 2P（拉丁/数字）；代码区：等宽字体 + 块状像素光标（代码本身必须易读，不用像素字体） |
| 质感 | CRT 扫描线覆盖层、像素边框（4px 阶梯阴影）、画面抖动（受伤）、8-bit 音效（WebAudio 方波合成，无音频文件） |
| 精灵 | 手绘 16×16 像素图，定义在 `js/pixelart.js`，Canvas 放大渲染（`image-rendering: pixelated`）：5 个关主 Boss + 1 个旅伴小骑士 + 图标组 |

## 3. 游戏结构

```
标题画面(PRESS START)
   └─ 世界地图：5 大关沿像素路径展开（锁定/解锁/星级）
        ├─ 每关 = 4~6 个小关卡（该难度梯度的代码片段）
        ├─ 每大关最后一关 = BOSS 战（限时 + 双方血条）
        └─ 符号/数字专项训练营（独立入口，tier 0）
   ├─ 每日挑战（按日期种子选题，额外 XP）
   └─ 修炼小屋（个人档案：等级/成就/按键热力图/WPM 曲线）
```

五大关对应教学梯度（内容库 tier 1~5）：
`顺序平原 → 分支峡谷 → 循环森林 → 函数城堡 → 综合遗迹`（Boss 各一，如「缩进兽」「分号幽灵」）

### Boss 战规则
- 限时（按代码长度动态计算），Boss 与玩家各有 HP。
- 敲对字符 → Boss 掉血（连击加成伤害）；敲错 → 玩家掉血 + 屏幕抖动。
- 打完代码 = 击杀；时间到或玩家 HP 归零 = 战败（可重试）。

## 4. 打字引擎（核心，js/engine.js）

- 代码渲染为逐字符 `<span>`；前导空格显示为淡色引导点 `·`，换行符显示 `↵`。
- **严格纠错模式**：敲错必须退格改正才能前进（训练指法记忆）；退格不能跨行。
- `Tab` 自动补齐当前行前导缩进（降低挫败感，仍计入击键）。
- **中文输入法检测**：`compositionstart` 触发警告覆盖层「⚠ 请切换英文输入法」——中国新生最常见的坑。
- 实时指标：WPM（(正确字符/5)/分钟）、CPM、准确率、当前连击、最高连击。
- 逐键统计：每个字符的错误次数、平均耗时，持久化到 localStorage。
- 星级评定：按 tier 动态阈值（速度 + 准确率双条件），1~3 星。

## 5. 成长系统

- **XP / 等级**：通关得 XP（基础分 × 星级 × Boss 加成），12 级称号（Lv1 打字史莱姆 → Lv12 键盘尊者）。
- **成就**：12 个（首杀、满连击、深夜修炼、全三星……），解锁时像素徽章弹窗 + 音效。
- **每日挑战**：日期种子随机一题，完成得双倍 XP，连续打卡计数。

## 6. 内容库（data/snippets.js，约 50 段）

| 类别 | 数量 | 内容 |
|---|---|---|
| Python tier1-2 | 14 | 顺序 / 分支 |
| Python tier3-5 | 14 | 循环 / 函数与数据结构 / PTA 综合 |
| C tier1-3 | 13 | 顺序 / 分支 / 循环 |
| C tier4-5 | 10 | 函数数组指针结构体 / PTA 综合 |
| 专项 drill | 10 | 符号专项、数字专项、高频短句 |

约束：代码纯 ASCII（避免输入法切换）、行宽 ≤ 42、4~14 行、语法正确可运行。

## 7. 技术架构（零构建、纯静态）

```
PixelTyper/
├── index.html          单页，所有屏幕为 <section> 切换
├── css/style.css       PICO-8 变量 + 像素边框 + CRT 层
├── js/pixelart.js      16×16 精灵定义 + canvas 渲染器
├── js/sfx.js           WebAudio 8-bit 合成音效
├── js/storage.js       localStorage 档案读写
├── js/engine.js        打字会话引擎（无 DOM 依赖，可单测）
├── js/app.js           屏幕路由 / 地图 / 结算 / 档案页
└── data/snippets.js    window.SNIPPETS（内容库）
    data/flavor.js      window.FLAVOR（关卡/成就/文案）
```

- 无框架、无构建步骤，`python3 -m http.server` 即可本地跑。
- 部署：tar 上传 → `docker cp` 进 oj-backend:/app/dist/PixelTyper/ → 即开即用。
